# hello-world-page

Atualizar a página 'hello-world-page' para incluir um formulário de contato e salvar os dados no Supabase.

## Stack

- HTML + CSS + vanilla JS
- Supabase + PostgreSQL
- Static hosting: GitHub Pages or Surge

## Setup

1. Open `index.html` and replace the Supabase URL and anon key with your project values.
2. Create the `leads` table and enable RLS if the app stores form data.
3. GitHub Pages URL: https://johncoelho.github.io/hello-world-page/

## Notes

- This project is intentionally static.
- Do not add a local backend, Node server, or SQLite database.
- Keep secret service keys out of the browser code.
